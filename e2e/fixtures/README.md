# Archivos de prueba

- `dorsal-prueba.ttf`: Manrope Regular reducida a letras (con tildes y eñe), cifras y espacio, sin
  ningún signo de puntuación, como una fuente de camiseta; renombrada «Dorsal Prueba». Sirve para
  probar el reemplazo de glifos por carácter. Licencia SIL Open Font License 1.1: ver
  `dorsal-prueba-OFL.txt` (la de Manrope, de donde sale).
